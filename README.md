# 📝 Beecrowd 2344 — Notas da Prova

Solução desenvolvida em **Java** para o exercício **2344 — Notas da Prova**, da plataforma Beecrowd.

O objetivo do exercício é receber uma nota numérica de `0` a `100` e convertê-la para um conceito representado pelas letras de `A` a `E`. :chatgpt-content-reference{index="0"}

---

## 📚 Objetivo

Este exercício trabalha principalmente com:

- Entrada de dados;
- Variáveis do tipo `int`;
- Estruturas condicionais;
- `if`, `else if` e `else`;
- Operadores relacionais;
- Verificação de intervalos;
- Conversão de valores numéricos em conceitos.

---

## 🧠 Lógica do problema

O programa recebe uma nota inteira entre `0` e `100`.

De acordo com o valor informado, deve exibir o conceito correspondente:

| Nota | Conceito |
|---|---|
| `0` | E |
| `1 a 35` | D |
| `36 a 60` | C |
| `61 a 85` | B |
| `86 a 100` | A |

Essas são as faixas definidas pelo próprio problema. :chatgpt-content-reference{index="1"}
